Key idea: one uv unit must cover the same number of pixels in x and y; multiply x by width/height.
Common mistakes: dividing instead of multiplying; using height/width; correcting before centering (shifts the center); correcting y instead (works but changes the range on the other axis).
Nudges: compare `d` at the right edge vs the top edge with the stepper (both 1). Ask how many pixels away each one is.
