Understanding Rogue Agent Collusion

Thhe following visualizations are a follow up to research done by Von Arx, et. al (collusion.wiki) on a summer 2026 incident where rogue internal OpenAI agents hijacked a message board to cheat on research evaluations.

I hope these data visualizations can help shed light on the following questions:

  1. How did agents figure out how to use a German Software Developer Wikipedia site to function as a message board?
  2. Using the Wiki, how did agents organize to share answers on evaluations? Is it possible to see an organizational pattern emerge over time?
  3. Was the collaboration effective?
